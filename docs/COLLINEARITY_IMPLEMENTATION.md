# P15 — Immutable numeric collinearity diagnostics

Updated 9 October 2026. This packet follows merged [PR #104](https://github.com/caglarsubas/auto_ml/pull/104), whose merge-main CI passed all five jobs. It partially advances D04, D05 and D12 in the [canonical ledger](product-roadmap.json). Complete outcomes and release/customer gates remain open.

Native initial training and candidate publication now retain a method-versioned numeric diagnostic snapshot for the exact execution and selected training predictors. Model status, detail inspection and assistant context distinguish finite values, unbounded dependence, constant or ineligible predictors, solver failures and exceeded diagnostic compute budgets. They no longer interpret universal VIF cutoffs as severity or automatic feature-removal rules.

## Method and scope

The snapshot uses the model's fitted/encoded **training inputs**, without targets, development-validation rows or final-outcome rows. It describes these inputs, including any fitted preprocessing. Non-finite numeric values use means computed on these training rows only; counts and means are recorded. Imputation can change dependence.

Declared category-derived predictors are excluded, including the exact output columns of one-hot groups and label, ordinal, manual-grouping, native-categorical, frequency and target encodings. Group membership comes from encoding provenance, not name-prefix matching. Non-numeric/boolean, constant, entirely non-finite and insufficient-row predictors receive explicit states. Exclusion does not mean a feature is unimportant or must be removed. Grouped categorical diagnostics remain future work.

Method `centered_scaled_auxiliary_ols_v1` subtracts a reference value, centers each eligible predictor and scales it to unit Euclidean norm. Overflow in reference subtraction uses a scaled fallback. For each predictor, NumPy's SVD-based least-squares solution regresses its normalized vector on the other normalized predictors. Because all vectors are centered, this is the centered auxiliary regression with an intercept represented by centering. VIF is the reciprocal of residual squared norm, with a lower bound of one to absorb floating-point roundoff. One eligible predictor has VIF one.

A residual norm at or below `8 × machine epsilon × max(matrix dimensions)` is reported as **unbounded / perfect or numerically indistinguishable**, with a JSON null value. This is a numerical tolerance, not a statistical test or evidence of exact dependence in the population. Rank, sample saturation and residual tolerance are recorded. Larger finite values remain descriptive; solver failure is separately unavailable. Numeric representation, mean imputation, sample size and correlated alternatives limit interpretation. Sampling uncertainty and paired model-change analysis remain unqualified.

The installed qualification baseline, **statsmodels 0.15.0**, already centers VIF inputs by default. It clips singular R-squared below one and can return a huge finite value. P15 makes centering explicit across supported dependency versions and separates that numerical state; it does not claim that this installed baseline computed uncentered VIF. See [statsmodels VIF](https://www.statsmodels.org/stable/generated/statsmodels.stats.outliers_influence.variance_inflation_factor.html) and [NumPy least squares](https://numpy.org/doc/stable/reference/generated/numpy.linalg.lstsq.html).

Details show signed/absolute pairwise correlations and the auxiliary VIF after omitting each other predictor. The decrease is numeric only when both values are finite. These are auxiliary regressions, **not model refits or proof that feature removal improves a model**. The UI offers no automatic significance, fairness, importance or removal gate.

## Immutable API and compute boundary

Each execution writes `diagnostics/collinearity.json` and a float64-only `diagnostics/collinearity.npz`, covered by the existing immutable execution manifest. Candidate execution recomputes its own subset snapshot instead of inheriting the parent's dependence structure. Parent files and current compatibility projections remain separate. Saved workflow refreshes use `GET /api/modeling/status/<file_id>/?execution_id=<saved UUID>` and reject missing, changed or unavailable exact executions; they cannot silently replace saved evidence with the latest dataset projection. Late restore responses cannot replace a newer selected execution.

`POST /api/modeling/vif-detail/` requires `file_id`, `feature` and the exact `execution_id`. It verifies manifest bytes and the recorded method/identity/dimensions, loads the native array with `allow_pickle=False`, and checks normalization. It never loads legacy mutable training pickle files, fitted model state or final outcomes. Manifest verification hashes sealed outcome bytes without deserializing them. Missing identity returns 400; an absent feature returns 404; historical, corrupt, unsupported or over-budget inputs return 409 with refit/selection guidance. Session authentication and CSRF remain mandatory.

The diagnostic engineering bounds are 100 numeric columns, 250,000 training rows and estimated auxiliary work `rows × numeric columns³ ≤ 100,000,000`. These cap repeated auxiliary solves, not model acceptance or a promised capacity profile. Exceeding a bound retains the full predictor list and unavailable states; training can still succeed. There is no sampling, silent feature trimming or shuffled validation fallback. Detail recomputation obeys the same recorded bounds.

SHA-256 detects corruption relative to the trusted controller's manifest; it is not an independent signature or protection against privileged database/filesystem mutation. The matrix is internal training-derived data and remains subject to the installation's storage and egress policy. Project authorization, retention, private production deployment and operational recovery remain open work.

## Review experience and qualification

The expandable numeric table covers all training predictors independently of SHAP availability. Finite and excluded/non-finite states remain inspectable. The dialog identifies the execution, training-row count and limitations; keyboard entry, trapped focus, Escape and focus restoration are exercised against a real authenticated backend. Delayed responses from a superseded feature or execution are rejected; assistant cache forwarding filters by the current execution and carries method, state and limitations. Historical values remain labeled method-unverified and require a new execution for this method.

The [qualification record](evidence/p15-qualification-2026-10-09.json) binds executable source, local reports and runtime identity. It covers centered-reference/analytic agreement, shifts/rescaling/extreme magnitudes, single predictors, singular and saturated samples, category-code permutations/output groups, nullable/non-finite inputs, compute bounds, solver failure, malformed/tampered archives, exact historical execution access, no pickle deserialization, actual session/CSRF and candidate-subset snapshots. Real browser workflows cover classification/regression replay and keyboard inspection of finite, unbounded and categorical-exclusion states.

This is bounded numeric diagnostic qualification. Full scientific workflow coverage, grouped categorical methods, paired uncertainty, comprehensive screen-reader/accessibility testing, independent reproduction, expert Python isolation, durable jobs and release/customer acceptance remain open. Historical artifacts are preserved, not retroactively certified.
